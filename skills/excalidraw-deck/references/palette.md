# Палитра — единственный источник цветов

Все цвета деки берутся только отсюда. Новый цвет = правка этого файла, не скрипта.

## Семантические роли (заливка, обводка)

| Роль | Заливка | Обводка | Когда |
|---|---|---|---|
| `blue` | `#a5d8ff` | `#1971c2` | факты, классика, техника, устройства |
| `violet` | `#d0bfff` | `#6741d9` | вступление, теория, рамка доклада, титул |
| `green` | `#b2f2bb` | `#2f9e44` | решения, «как правильно», позитивный полюс сравнения |
| `amber` | `#ffec99` | `#f08c00` | ключевые формулы, баннеры-выводы, часть-акцент |
| `red` | `#ffc9c9` | `#e03131` | анти-паттерны, пределы, негативный полюс сравнения, финал |
| `gray` | `#e9ecef` | `#495057` | нейтральное, плейсхолдеры, скриншоты-заглушки |

## Текст

| Роль | Цвет | Где |
|---|---|---|
| `INK` | `#1e1e1e` | заголовки, тело |
| `MUTED` | `#495057` | подзаголовки, стрелки |
| `FAINT` | `#868e96` | источники, сноски |
| `NUMBER` | `#adb5bd` | номера слайдов |

## Правила

1. На слайде один доминирующий акцент (роль секции) + максимум один семантический
   контраст (например, красный против зелёного в сравнении). Больше — пёстрая каша.
2. Роль секции сквозная: пилл-надзаголовок, подчёркивание и номер слайда — одним цветом.
3. Заливки всегда мягкие (см. таблицу); насыщенный цвет — только обводка и тонкие линии.
4. Шрифты: `fontFamily: 2` (чистый гротеск) по умолчанию; `1` — рукописный Excalifont
   для небрежных пометок; `3` — моно для кода/идентификаторов.
