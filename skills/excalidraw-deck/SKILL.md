# Excalidraw Deck — колоды, которые спорят

Генерирует `.excalidraw`-файлы, где каждый слайд — фрейм, а визуал несёт аргумент,
а не оформляет маркированный список. Опирается на две идеи: «диаграмма должна
ARGUE, а не DISPLAY» (isomorphism-тест: убери текст — структура всё ещё читается?)
и «фиксированная сцена»: слайд не перетекает, не масштабируется и не рефловится.

## Когда НЕ генерировать

- Файл уже правился владельцем вручную и задача — точечная правка: редактируй
  существующие элементы (сдвиг, замена text), не пересобирай деку. Урок: ручные
  правки владельца (подпись, панели-заметки) стираются перегенерацией.
- Нужен pptx/PDF — это другой жанр, excalidraw-дека живёт в Excalidraw.

## Анатомия деки

- Слайд = `frame` 1920×1080, имя `NN · метка`, дети помечены `frameId`.
- Фреймы столбиком с зазором 240 (смотри деку скроллом, Excalidraw — бесконечный холст).
- Право фреймов (x > 2040) — зона заметок владельца: панели, скриншоты-заготовки. Не фреймить.
- Каждый слайд: пилл-надзаголовок с ролью секции, заголовок fs40, подчёркивание
  акцентом, номер `NN` в правом верхнем углу.

## Workflow

1. Канва → план слайдов. Если есть md-доклад с блоками «**На слайде:**» — план уже
   написан, бери оттуда; речь не тащится в деку (слайд ≠ конспект доклада).
2. Скрипт на библиотеке: `sys.path.insert(0, <skill>/scripts)` →
   `from excalidraw_deck import Deck` → `deck.slide(...)` → `deck.merge_into(path)`.
   Стили слайдов — `references/templates.md`, координатные формулы готовы.
3. `deck.validate()` (или `python3 scripts/validate_deck.py file.excalidraw`) —
   FAIL чинить до сдачи, WARN читать глазами.
4. Открыть в Excalidraw глазами: баланс, воздух, пустые углы. Рендер — субъективная
   приёмка, валидатор её не заменяет.

## Режим слияния — правки владельца первичны

`deck.merge_into(path)` вместо `save()` — единственный способ обновлять живую деку,
которую владелец правит руками. Каждый сгенерированный элемент несёт стабильный ключ
`customData.deck-key` (слайд/тип/порядок), рядом с декой живёт манифест
`<файл>.manifest.json`. Политика наложения плана:

- позиция, размер, цвет, стиль существующего элемента — **всегда владельца**, план не трогает;
- текст обновляется, только если владелец его не правил (план помнит свой текст в
  `customData.gen_text`); правленый текст при изменившемся плане = конфликт —
  остаётся текст владельца, конфликт попадает в отчёт;
- элементы владельца без ключа неприкосновенны; удалённое владельцем не
  восстанавливается (учёт по манифесту); ничего не удаляется автоматически;
- первый прогон по немаркированной деке = `baseline` (полная запись с ключами);
  сами ключи владелец в Excalidraw не видит и случайно не ломает.

Ограничение: ключи привязаны к порядку вызова в плане — перестановка слайдов/шагов
в плане меняет ключи (старые элементы станут «осиротевшими», отчёт их покажет).
Перестановкам предпочитай правку текста плана.

## Железные правила текста

- Текст внутри фигуры — **всегда bound**: `containerId` + у фигуры
  `boundElements: [{id, type:"text"}]`, `textAlign/verticalAlign`,
  `autoResize: false`, ширина = `контейнер − 2·PAD`. Тогда перенос строк делает
  Excalidraw и вылезание за фигуру физически невозможно.
- Свободный текст (заголовки, строки) — `autoResize: true`, `originalText = text`.
- Ширины/высоты элемента программа задаёт честно (оценка по глифам из
  `est_wrapped_height`) — от них зависят рамки выделения и валидатор.
- `fontFamily: 2` по умолчанию; палитра — только из `references/palette.md`.

## Дизайн-система

- **Спейсинг** — `references/spacing.md`: токены margin 120 / gutter 60 /
  step 68–78 / block 120, одна левая ось, заполнение зоны по вертикали.
  Слайд-«сирота» (контент меньше половины зоны) — растить кегли, а не оставлять пустоту.
- **Кегли** — шкала в `references/templates.md`: body 28, карточки 26, заголовок 64,
  титул 72. Проектор 1080p прощает крупное и не прощает мелкое.
- **Пресеты** — `references/style-presets.md`: `Deck(theme="handdrawn"|"clean"|"dark")`.
  Один пресет на деку; палитра ролей общая, меняются бумага/чернила/характер линии.
- **Инфографика** — `references/infographics.md`: `timeline / bars / stat` в библиотеке,
  матрица и ступени — рецептурой. Честные пропорции, единицы, одна диаграмма на слайд.

## Gotchas формата

- Программным элементам не нужен `index` (дробный порядок Excalidraw) — он
  регенерируется. Унаследованным элементам при точечной правке — сохранять.
- `points` у стрелок/линий относительные; `width/height` = абс. размеры; сдвиг
  элемента = сдвиг `x/y`, points не трогаются.
- `roundness: {"type": 3}` — скругление прямоугольников, `{"type": 2}` — кривизна
  стрелок, `null` — без.
- Bound-тексту нужны `originalText` и `baseline ≈ fontSize·1.05` (family 2) — без
  них Excalidraw пересчитывает блок при первой правке и центровка плывёт.
- Фрейм рисует подпись слева сверху; не клади контент в первые 60px фрейма.
