# Шаблоны слайдов (фрейм 1920×1080, локальные координаты)

Контентная зона: x=120…1800, y=90…1020. Все размеры — стартовые, варьируй по объёму текста.

## Титул
- пилл-рамка «ТЕЗИС · ВОПРОС» (120, 100), роль = акцент доклада
- заголовок fs46 (120, 170), до 2 строк
- подчёркивание (120, ~320, w=120)
- подзаголовок fs24 MUTED (120, 360)
- автор fs20 (120, 430); источник fs16 FAINT (120, 480)

## Обычный слайд
- пилл «ЧАСТЬ N · КЛЮЧ» (120, 96) — цвет роли секции
- заголовок fs40 (120, 150); подчёркивание (120, 205); номер — `slide.number()`
- контент с y=260

## Карточки в ряд (n штук)
`w = (1680 − (n−1)·60) / n`; x = 120, 120+w+60, …; y=300; текст fs20.
Для «тройка требований»: 3 × 520px. Подпись-строка под карточками y = 300 + h + 50.

## Сравнение (2 колонки)
Слева красная карточка (анти-паттерн), справа зелёная (как надо):
x=120 w=760 и x=920 w=760, y=300. Вывод-баннер amber на всю ширину ниже.

## Поток (конвейер)
Боксы h=52 fs16 серые: w = max(len·16·0.52+34, 110); стрелки между —
`arrow(x+6, y+26, 26, 0, curve=False)`. Строки-пояснения ниже с шагом 48.

## Цикл (замкнутый луп)
4 карточки 600×110 по углам прямоугольника: (360,300) → (1060,300) →
(1060,560) → (360,560). Стрелки: вправо (974, 355, 72, 0), вниз
(1360, 424, 0, 122), влево (1046, 615, −72, 0), вверх (660, 546, 0, −122).
Подпись возврата «и снова» amber у средней стрелки. Луп обязан замыкаться.

## Строки-тезисы
`row(120, y, текст, fs=20)`, шаг 44–56 по длине. Больше 5 строк на слайд —
плохо: переноси на карточки или режь.

## Баннер-формула
amber-карточка fs22 на 900–1100px, 1–2 строки. Один на слайд, максимум два.

## Плейсхолдер скриншота
gray-карточка h=150: «[ скриншот … ]» + подпись. Реальный скриншот вставляет
владелец в Excalidraw вручную.

## Q&A
пилл «ВОПРОСЫ», «Q&A» fs72, подчёркивание, 2 строки контактов/источников fs20 MUTED.
