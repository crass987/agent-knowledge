# Заведение нового паттерна в сканер

Кандидат приходит из трёх мест: правка владельца (основной источник), собственная
находка при чтении, публичные списки Ильяхова. Прежде чем вносить — прогнать через
тесты различения: сканер хранит только подтверждённые дефекты, не «модные слова».

## Четыре теста различения (калька или нет)

1. **Корпусный.** Встречается ли сочетание у носителей в *непереводных* текстах?
   Проверка: НКРЯ (ruscorpora.ru), Gramota.ru, точный поиск фразы в кавычках.
   «Пишут только переводчики и корпоративные блогеры» = калька.
2. **Обратный перевод.** За фразой стоит идиоматичный английский оборот, и она
   существует только через это отображение? «На ежедневной основе» ← *on a daily
   basis* — калька; носитель скажет «ежедневно».
3. **Сочетаемостный.** Слово в русском есть, а данного сочетания нет: «сделать
   резолв» — носитель скажет «решить».
4. **Параза.** Есть простое слово, которым носитель заменит без потери смысла?
   «Вокабуляра» → «словарь» — калька.

Происхождение слова — не приговор: «менеджер», «дашборд», «по умолчанию» освоены
и кальками не являются. Калька — это конструкция, скопированная из английского
там, где у русского есть свой ход.

## Куда класть найденное

- **Конкретная фраза** (как в таблицах Класса 2) → literal-запись в
  `scripts/calque_patterns.json`, тир `calque`.
- **Семейство фраз** (Класс 1, канцелярит) → regex в тот же файл, тир по классу.
- **Нужен длинный разбор, примеры или исключения** → таблица в
  `references/translationese.md` + короткий паттерн в JSON (ссылка в `source`).
- **Шумное, но полезное** (ложные срабатывания на чистых текстах) → тир `loose`:
  показывается только с `--loose`.

## Формат записи (`calque_patterns.json`)

`id` (латиницей, с префиксом класса) · `tier` (`calque` / `officialese` / `hybrid` /
`stop` / `loose`) · `check` (regex) · `fix` (что написать вместо) · `source`
(откуда паттерн: «правка владельца 2026-XX-XX», «evals b01», «translationese.md
Класс 2»).

## Проверка перед коммитом

1. `python3 scripts/calque_scan.py --selftest` — зелёный: слоп-фикстуры из
   `evals.json` ловятся, чистый текст и allowlist-гибриды дают ноль.
2. Precision-прогон: сканер по 2–3 прошлым чистым (ваши глазами) документам —
   новые паттерны не должны давать ложных срабатываний. Дают → тир `loose`
   или сузить regex.
3. Помнить: находка не приговор (SKILL.md «Что такое сдано») — сканер предлагает,
   решает человек.
