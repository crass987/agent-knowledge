# Палитра — единственный источник цветов

Все цвета деки берутся только отсюда. Новый цвет = правка этого файла и THEMES в
`scripts/excalidraw_deck.py`, не скрипта генерации.

## Закон контраста (WCAG)

- Текст на заливке или бумаге — **≥ 4.5:1** (крупный текст fs ≥ 40 — ≥ 3:1).
- Цвет текста роли — третий компонент роли, он темнее обводки и проверен на бумаге темы.
- Обводка/линия — НЕ цвет текста: насыщенный оранж `#f08c00` на белом даёт 2.5:1.
- Цвет надписи на фигуре выбирает `text_on()` по яркости заливки, а не автор.
- Валидатор считает контраст для каждого текста: FAIL ниже порога, WARN ниже 7:1
  у основного текста (fs ≥ 22). Панели владельца (ключи `panel/*`) — только WARN.

Бумага `#1a1a1a`, чернила `#f1f3f5`. Заливки глубокие, обводки и текст — светлые
насыщенные (контраст 7–12:1).

## Служебные цвета текста

| Роль | Светлая | Тёмная |
|---|---|---|
| `ink` (заголовки, тело) | `#1e1e1e` | `#f1f3f5` |
| `muted` (подзаголовки) | `#495057` | `#ced4da` |
| `faint` (сноски, источники) | `#71757c` | `#adb5bd` |
| номер слайда | текст роли | текст роли |

## Правила

1. Один доминирующий акцент на слайд (роль секции) + максимум один семантический
   контраст (красное против зелёного в сравнении).
2. Пилл, подчёркивание и номер слайда — одним цветом роли; текст пилла и номера —
   текстовый компонент роли, не обводка.
3. Заливки мягкие/глубокие по теме; насыщенный цвет — обводка, линия и текст роли.
4. Шрифты: `fontFamily: 2` по умолчанию; `1` — рукописный; `3` — моно для кода.
