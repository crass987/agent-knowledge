# Спейсинг — система отступов

Числа из этой таблицы — единственные расстояния в деке. Всё остальное кратно им.

## Токены

| Токен | px | Что |
|---|---|---|
| `margin` | 120 | поля слайда слева/справа (x=120…1800) |
| `gutter` | 60 | зазор между карточками в ряду |
| `gutter-sm` | 40 | зазор между чипами и флоу-боксами |
| `step` | 68–78 | шаг строк тела (растёт с объёмом текста); титул и Q&A — 50–60 |
| `pad-card` | 40 | внутренний отступ карточки (сверху+снизу суммарно больше: высота = текст + 40) |
| `block` | 120 | минимум между смысловыми группами на слайде (заголовок ↔ контент, карточки ↔ вывод) |
| `line` | 0 | подчёркивания, разделители — не добавляют отступа, кладутся в `block`-зону |

## Правила

1. **Одна левая ось.** Все элементы начинаются с x=120. Вторая колонка — x=960
   (половина) или сетка карточек. Никаких «на глаз».
2. **Заполнение по вертикали.** Контент от y≈340 до y≤1000. Если контент занимает
   меньше половины зоны — растить кегли/карточки, а не оставлять пустоту снизу.
3. **Оптический центр.** Пустой остаток снизу допустим, если он ≤ остатка сверху
   плюс один `step`. Слайд, прижатый к заголовку, — сирота.
4. **Воздух — дизайн.** Между группами держи `block`; теснота читается как «эти
   куски — одно», поэтому лишний отступ лучше лишней рамки.
5. **Стрелки не касаются фигур** — зазор 14–16px с каждой стороны.

## Что не токенируется (структурные зазоры)

- Колонки через полслайда (x=120 и x=960) — зазор следует из сетки, не из `gutter`.
- Циклы и схемы: зазоры между карточками цикла — там, где проходят стрелки.
- Чипы в ряду — `gutter-sm`, не `gutter`.
