# Пресеты стилей

Вариативность = выбор пресета ДО генерации. В одной деке — один пресет, смешивать нельзя.
Задаётся при создании: `Deck(theme="handdrawn")`. Палитра ролей (references/palette.md)
одна для всех пресетов — меняются бумага, чернила и характер линии.

## `handdrawn` — дефолт: живой маркер-боард

- бумага `#ffffff`, чернила `#1e1e1e`, roughness 1, fontFamily 2
- мягкие заливки ролей, обводки насыщенные
- вайб: рабочий техвечер, набросано при всех, но ровно

## `clean` — строгая доска

- бумага `#ffffff`, чернила `#1e1e1e`, roughness 0, fontFamily 2
- те же заливки; линии strokeWidth 2; стрелки прямые (curve=False)
- вайб: документ, апрув-версия; когда «нарисованный» характер неуместен

## `dark signal` — тёмная сцена для проектора

- бумага `#1a1a1a`, чернила `#f1f3f5`, muted `#ced4da`, faint `#adb5bd`, roughness 1
- заливки ролей оставить мягкими светлыми — на тёмном они становятся фокусом;
  серый `gray` заменить на `#343a40`/`#adb5bd`
- один яркий акцент на слайд (amber/red) — «Bold Signal» из frontend-slides:
  доминирующий цвет + резкий акцент бьют ровную пестроту
- осторожно с панелью-заметками владельца: её цвета под светлую тему

Выбор: доклад для людей → `handdrawn`; артефакт для чтения/апрува → `clean`;
сцена в тёмном зале → `dark signal`.
