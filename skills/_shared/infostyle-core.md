# infostyle-core — общее ложе инфостиля Ильяхова / Бюро

Опорный референс. На него ссылаются `jtbd` (job-story + заголовок задачи) и
`infostyle` (проза для людей), чтобы правило жило в одном месте. Здесь — **базис**,
общий для любого текста и любой формулировки. Проза-специфика (слово → предложение →
абзац → текст, проходы редактуры) — в `skills/infostyle/SKILL.md`.

Дословные цитаты и источники — в `skills/infostyle/sources.md` и
`skills/jtbd/sources.md`.

## Главная мысль

Оценка не убеждает — убеждает факт. Оценочные слова («удобный», «эффективный»,
«быстро», «выгоднее») — яд: они не создают доверия и не доносят мысли. Каждое
оценочное слово замените измеримым фактом — цифрой, сроком, проверяемым состоянием
или конкретной сценой — либо удалите.

## Базис: общие принципы для любого текста

1. **Факт вместо оценки.** Оценочное прилагательное — сигнал к переработке: удалить
   или раскрыть через измеримый факт. «Быстро» → «за 5 секунд»; «удобный» → «без
   переключения между вкладками»; «качественный свет» → «яркость от 500 люкс».
2. **Чувственная конкретика («внутренний фильм»).** Каждую часть текста можно
   представить как конкретную сцену — картинку, действие, объект на экране.
   Абстракции («нагрузка», «оптимизация», «эффективность», «совокупная стоимость
   владения») нельзя представить → им нельзя поверить → их надо прибить к реальности
   конкретикой.
3. **Конкретный читатель + его язык.** Один человек в одной ситуации, слова, которыми
   он реально мыслит. Не «для всех / любая задача». Текст пишется для того, кто его
   прочтёт, а не для абстрактной аудитории.
4. **Прямая польза, не похвала продукта.** Что читатель получит или сможет сделать,
   а не что мы запускаем или чем гордимся. Польза шире денег: сэкономить время,
   избежать ошибки, восстановить справедливость, развлечься — всё это польза.
5. **Понятность важнее креатива.** Без метафор, рифм, антитез, фразеологизмов, клише,
   канцелярита, рекламных штампов. Если в фразе есть «ход» или «приём» —
   переписывайте в прямую номинацию.

## Чёрный список оценочных слов (стоп-слова)

Прогоняйте через этот список **каждую** формулировку, заголовок и абзац перед сдачей.

**Стоп-слова (оценки без меры):** быстро, вовремя, медленно, адекватный, разумный,
понятный, реальный, справедливый, обоснованный, приемлемый, качественный, удобный,
эффективный, полноценный, полный, надёжный, современный, инновационный, оптимальный,
профессиональный, мощный, гибкий, выгоднее, дешевле, лучше, круче, выигрывает,
премиальный, эксклюзивный, уникальный.

**Правило замены:** для каждого стоп-слова спросите «какой факт за этим стоит?» и
впишите измеримое.

| Стоп-слово | Замена (факт) |
|---|---|
| быстро | за 5 секунд / одним взглядом / в один экран |
| вовремя | до демо / до конца спринта / до 18:00 пятницы |
| адекватная цена | цена в диапазоне медианы по сопоставимым объявлениям |
| выгоднее / дешевле | окупается за N месяцев / в 3 раза дороже при покупке, но ест в 10 раз меньше |
| понятный / удобный | с указанием ставки и базы / без переключения между вкладками |
| качественный свет | яркость от 500 люкс, цветопередача 90+ |
| реальная цена | средняя цена по 20 последним объявлениям в моём городе |
| без сюрпризов | фиксированная сумма — N ₽ в месяц |

Если факта нет в контексте — его надо добыть (изучить реальный объект) или убрать
слово. Оставлять оценку «для красоты» нельзя.

## Критический мета-слой: как НЕ применять инфостиль

Это отличие живого инфостиля от наивного. Наивный редактор бездумно удаляет
«является» и «наилучший» — и получает сухой мёртвый текст. Живой редактор думает о
читателе.

- **Мусор субъективен.** Мусор — это всё, что ваш *конкретный* читатель не уловит в
  тексте, а не фиксированный список слов. Для специалиста термин — рабочий инструмент;
  для новичка — мусор. Сначала определите читателя, потом решайте, что мусор.
- **Не вытравливать местоимения «кислотой».** Текст обязан звучать естественно, как
  речь. «Мы доставим ваш заказ в удобное для вас время» → «Доставим заказ, когда вам
  удобно», а не «Доставка осуществляется в согласованное время». Удаляйте только
  *избыточные* местоимения.
- **Не привязывайтесь к словам — вкладывайте смысл.** «Пишем просто и понятно о
  сложном», «помогаем решать задачи бизнеса» — расхожие фразы, за которыми ничего не
  стоит. Это мусор, даже если слова «по правилам». Противоядие — примеры и
  доказательства: «объясняем, что такое банкротство, как забирают жильё за долги и
  почему ЦБ отзывает лицензии».
- **Один приём — одно место.** Перечисление требует обобщающего ключа, иначе читатель
  устаёт сканировать. «Пишу и редактирую текст для журналов, сайтов, блогов и
  промостраниц на тему ИТ, гаджетов и безопасности» → «Пишу и редактирую статьи для
  интернета: журналов, сайтов, блогов. Любимая тема — технологии: ИТ, гаджеты,
  безопасность».
- **Термин — только если читатель его знает.** Жаргон своей тусовки («ФФФ», «прибить
  гусеницу», «KPI», «JTBD») для неподготовленного читателя — мусор. Пишите для широкого
  круга — объясняйте; пишете для своих — можно без расшифровки.

## Общие сканеры (прогонять всегда)

Эти три — для любого текста, включая короткую формулировку и заголовок. Остальные
проходы (глагол, сильная позиция, «одна мысль», перечисление) — в
`skills/infostyle/SKILL.md`, они нужны прозе.

- **Стоп-сканер:** есть ли слово из чёрного списка? Для каждого — факт.
- **Латиница-сканер (для русского текста):** ни одного русского слова с латиницей
  внутри. Бренды и аббревиатуры (iPhone, LED, CRM, B2B, KPI) — ок. Слово вроде
  «пауsmarty» — сбой, пересоберите.
- **Вычитка вслух:** прочитайте текст вслух. Там, где не хватает воздуха, — слишком
  длинное предложение; где спотыкаетесь, — языковой сбой. Сказать «вычитал» — мало:
  реально прогоните текст.
