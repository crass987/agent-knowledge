# Переводизм-сканер — отдельный проход после стоп-сканера

Стоп-сканер (`references/infostyle-core.md`) ловит стоп-слова и оценки. Но он **пропускает
переводизмы** — английские конструкции, перенесённые в русский дословно. Они-то и
дают эффект «звучит не по-русски» в текстах, пришедших из английского: переводах,
локализованных доках, артефактах из англоязычного канона (NMT), LLM-выходе из
EN-источника.

Этот проход — **условный**: запускайте его, когда знаете или подозреваете, что текст
русифицирован с английского. Прогоняйте **после стоп-сканера**, отдельным проходом.

## Когда запускать

- Текст — перевод или локализация с английского.
- Артефакт сгенерирован скиллом из англоязычного канона (NMT: market-research,
  craft-value-proposition, product-requirements, craft-go-to-market).
- LLM-выход, чей источник или промпт были на английском.
- Признаки: дефисные гибриды (`won-аккаунты`), английские существительные внутри
  русских фраз, «кальки» («жизнь упрощается», «стоит на допущении»).

## Allowlist — оставляем по-английски (НЕ флагаем)

Эти термины устоявшиеся, переводить их не надо:

- **Методологические (NMT/JTBD-канон):** `Job`, `Core Job`, `Big Job`, `RAT`. Это
  узнаваемые термины методологии — оставляем как есть.
- **Доменные аббревиатуры и имена:** `SaaS`, `SDK`, `API`, `RUM`, `DEM`, `APM`,
  `BTM`, `OTel`, `ClickHouse`, `MVP`, `TAM`, `SAM`, `SOM`, `LOI`, `ACV`, `CAC`,
  `SLA`, `SLO`, `KPI`, `B2B`, `on-prem`, `web`, `mobile`, `frontend`, `backend`,
  `source map`, `session replay`, `Web Vitals`, имена продуктов и вендоров.

Правило: если термин привычен в русском IT-дискурсе — оставляйте. Сомневаетесь —
флагайте (Класс 3), пусть решает редактор.

---

## Класс 1. Кальки-оборотчики

Английская конструкция, переведённая русскими словами дословно. Читается неестественно.
Ищите по паттернам; ниже — типовые находки из реальных артефактов.

| Калька (плохо) | По-русски |
|---|---|
| жизнь заказчика упрощается | заказчику проще / работа упрощается |
| вписать категорию в голову покупателя | сформировать у покупателя категорию |
| связывающее ограничение | ограничение, которое всё решает / узкое место |
| стоит на [допущении] (×N) | опирается на / держится на |
| верх цепи | начало цепи |
| цепочка к прибыли | цепочка, ведущая к прибыли |
| шлюз экзистенциального риска: PASS | проверка на неприемлемый риск: пройдена |
| зонд спроса | проверка спроса |
| порядок величины | порядок числа / масштаб |
| временная дыра | временной разрыв / окно уязвимости |
| право играть / право доставить Job | право участвовать на рынке / способ доставить решение |
| компаундируется на активах | накапливается на активах / усиливается активами |
| демпфер-паритет | оборонительный паритет |
| закроют рассмотрение | закроют потребность / выиграют тендер |
| Big-Job-возвышенность | более высокий уровень надзадачи |
| local-optimum-ход | ход локальной оптимизации |
| размазанных по агенту | разнесённых на уже развёрнутый агент |
| фигуры (для чисел) | числа / показатели |
| под Положением ЦБ | по Положению ЦБ |
| Displace мимо | вытеснение отпадает |
| ошибочен вход | входные данные неверны |
| Он причинен | Он причинно обусловлен / Это причина, а не ярлык |

## Класс 2. Дефисные EN-ru гибриды

Русский и английский склеены через дефис в одно слово. Regex-признак:
`[A-Za-z]+-[а-яё]+` или `[а-яё]+-[A-Za-z]+`.

**Гибрид через пробел — тоже гибрид.** Английское определение перед русским
существительным без дефиса (`stack-trace группировка`, `fake-door предложение`,
`release-tracking`, `honest money тест`) — та же болезнь, regex выше её пропустит.
Ищите визуально: EN-слово + пробел + ru-существительное в роли определения.

- **Плохо:** `won-аккаунты`, `build-дельта`, `funnel-аналитика`, `revenue-воронки`,
  `synthetic-прозвон`, `sovereign-контура`, `product-владельцем`, `Value-гипотеза`,
  `error-tracking-пакет`, `GMONIT-паритет gap`, `concierge-прогон`,
  `stack-trace группировка`.
- **Допустимо (EN-термин + RU-родовое):** `SaaS-решение`, `API-ключ`, `IT-компания` —
  если EN-часть устоявшийся термин, а RU-часть родовое существительное. Решение за
  редактором; при сомнении — переводите.

**Фикс:** перевести обе части (`won-аккаунты` → наши аккаунты; `build-дельта` → объём
разработки) либо вынести термин курсивом без дефиса (`funnel-аналитика` → аналитика
воронки).

## Класс 3. Английские слова вне allowlist

Английские существительные/глаголы внутри русских предложений, не из allowlist.
Решите по контексту: **перевести** или **оставить** (и тогда один раз расшифровать,
а при повторах — добавить в локальный allowlist).

Кандидаты, часто встречающиеся в NMT-артефактах: `Consideration Set`, `Aha` (Moment),
`wedge`, `climb-a-level`, `kill` (как существительное), `make-or-break`,
`switchable demand`, `displacement`, `lock-in`, `switching cost`, `win-rate`,
`attach-rate`, `honest money`, `fake-door`, `concierge`, `overage`, `head-to-head`,
`turnkey`, `shipping`, `resource dilution`, `compliance-evidence`, `PASS`, `build`
(как существительное), `fit`, `caveat`.

**EN-существительное в русской позиции — переводить.** Если английское слово стоит
как подлежащее/дополнение или «склоняется» русским контекстом (`build` как сущ.,
`kill` как сущ., `fit`, `caveat`, `buyer`, `shipping`, `PASS`) — это не термин, а
англицизм. Переводите: разработка / критерий провала / соответствие / оговорка /
покупатель / отгружается / пройден.

**Канонические термины второго эшелона** (`Consideration Set`, `Aha` (Moment),
`wedge`, `climb-a-level`) — НЕ в allowlist, но и не обычные англицизмы. При первом
упоминании — курсивом с русской расшифровкой, далее — русским эквивалентом (набор
вариантов / момент озарения / клин / подъём на уровень). Иначе по тексту идёт
сплошной английский.

> `Job`, `Core Job`, `Big Job`, `RAT` — **в allowlist, не трогаем.**

## Как фиксить

- **Калька** → естественный русский оборот (таблица Класса 1).
- **Гибрид** → перевести обе части или вынести термин курсивом без дефиса.
- **Англ. слово вне allowlist** → перевести; если термин устоявшийся для аудитории —
  оставить и один раз расшифровать.
- **Грамматика:** после замены проверьте согласование и порядок слов — калька часто
  ломает и грамматику («Объясняет цепочка», «спрос и каналы рвётся»).

## Чек-лист прохода

- [ ] Нет дефисных EN-ru гибридов (или каждый осознанно оставлен).
- [ ] Нет кальк-оборотчиков из таблицы Класса 1.
- [ ] Английские слова — только из allowlist (или осознанно оставленные термины).
- [ ] После замен согласование и порядок слов не сломаны.
- [ ] Имена собственные проверены — не обрезаны при генерации (например, `Замесин`,
  а не `Замин`; `Zamesin`).
