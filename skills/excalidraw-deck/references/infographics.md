# Инфографика

Слайд с данными спорит цифрой, а не прилагательным. Паттерны ниже — готовые формы;
методы `timeline/stat/bars` есть в библиотеке, остальное собирается из карточек.

Правила данных: подписывай единицы; пропорции — честные (бар длиной по значению);
одна диаграмма на слайд; вывод цифры — баннером, а не прятать в подпись.

## Timeline — `slide.timeline(x, y, w, items)`

Горизонтальная линия (strokeWidth 3, цвет акцента), точки-эллипсы 16×16 по числу
событий, равномерно; под каждой точкой подпись fs22 (2 строки макс).
`items: [(текст, роль|None)]` — роль красит точку. Слоты точек при >5 событиях —
сужай подписи, а не линию.

## Bars — `slide.bars(x, y, w, items)`

Горизонтальные бары: слева лейбл fs24 (колонка 340px), бар — прямоугольник
`длина = (w−420) · значение/максимум`, h=48, заливка роли, значение справа от бара
fs24. Шаг 76. Сортируй по убыванию — сравнение читается до чтения подписей.

## Stat — `slide.stat(x, y, число, подпись, accent)`

Гигантская цифра fs120 цветом акцента + подпись fs28 MUTED под ней. Для «одной
цифры-удара» (2,9 с; 80 спанов; −70%). Два стата на слайд — максимум, рядом с
осью симметрии x=960.

## Матрица 2×2

Оси: две линии (line, strokeWidth 2) крестом, подписи осей fs22 на концах;
четверти — карточки без заливки, по одной фразе fs26. Для «карт решений».

## Ступени / воронка

Карточки убывающей ширины по центру (800 → 620 → 440), выровнены по верху,
стрелок не нужно. Каждый уровень — одна фраза + число.

## Что НЕ инфографика

Список иконок-эмодзи, обёрнутый в «схему»; диаграмма без вывода; более одной
диаграммы на слайд. Если визуал можно выкинуть и смысл не изменится — это не
инфографика, это украшение (isomorphism-тест из SKILL.md).

## Waterfall трейса — как в APM-разделе (обложки и «как это выглядит»)

Продуктовый вид: слева колонка подписей спанов (точка сервиса цветом роли +
имя, отступ 26px за уровень вложенности), справа общий таймлайн — ось
`slide.hline` с подписями «0 · 1 с · 2 с», вертикальная сетка
`slide.connector` цветом faint, бары `slide.bar` пропорционально времени
(spans: имя, depth, t0, t1, роль, длительность). Длительность — на баре
fs18 цветом `text_on(заливка)` при ширине ≥ 90px, иначе справа от бара;
Error — текстовым цветом роли. Шаг строк 78, бар h=40.

Абстрактный вариант (без оси): бары со сдвигом по глубине + связи
`connector` от низа родителя до верха ребёнка — коридор x по левому краю
ребёнка, чтобы не пересекать соседние бары.
