# Гигиена — последний проход

Гигиена чистит слова, но не чинит текст без полезного действия: «натёртый пол в доме
без стен». Сначала архитектура (`architecture.md`), потом это.

Почти всё ниже ты делаешь сам — это базис Ильяхова. Пробегись быстро, не геройствуй.
**Без напоминания ты пропустишь два пункта** — они и есть ради этого прохода.

## Два, что пропустишь без напоминания

1. **Кальки-переводизмы.** Стоп-сканер к ним слеп — «английских» слов нет, сбой
   синтаксический («работы уровнем выше», «детализация на уровне хостов»). Для текста
   из EN-источника (канон, код, доки, LLM, перевод) проход обязателен. →
   `translationese.md`, Класс 1 — первым.
2. **Монотонность длины.** Три предложения подряд одной длины (±2–3 слова) — главный
   маркер машинного текста, даже когда стоп-слов и кальк нет. Чередуй длины, дай абзацу
   дугу: зачин → развитие → удар. → `rhythm.md`.

## Быстрая страховка (то, что ты и так делаешь)

Пробегись — не как чек-лист «выполнено = сдано»:

- **Стоп → факт.** Оценочное слово («быстро», «удобный», «эффективно») — в измеримый
  факт или в мусор. Список — `_shared/infostyle-core.md`.
- **Глагол, не отглагольное.** «Производит оплату» → «платит»; «принятие решения» →
  «решает».
- **Одна мысль** на предложение и на абзац. Вторая — дроби.
- **Сильная позиция.** Суть в первое предложение, не в конец.
- **Латиница.** Ни одного русского слова с латиницей внутри (бренды и аббревиатуры — ок).
- **Вслух.** Прочти реально; где не хватает воздуха — руби.

Языковые сбои — двусмысленность, паронимы, однокорневой повтор, случайная рифма —
ловятся одним проходом, чтением вслух; отдельных сканеров не нужно.

## Не сушить рабочий документ

Плотность лендинга (телеграф, выжимка), применённая к аналитическому документу, даёт
мёртвый конспект. Рабочий документ организуют, не сжимают. → `SKILL.md` Шаг 0,
`genres.md`.

## Сдача не по сканерам

Зелёные сканеры **не означают живой текст** — формально чистое бывает мёртвым. Гейт —
независимый критик (`infostyle-critic`, см. `SKILL.md`), не твой самоотчёт. Себя по
сканерам не сертифицируешь.
