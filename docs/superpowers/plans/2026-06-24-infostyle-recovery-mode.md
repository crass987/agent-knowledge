## [6] А.Н. Беззубов. «Введение в литературное редактирование» (СПб, 1997)

**О чём.** Учебное пособие по микроредактированию — теория и таксономия текстовой

**Ключевые цитаты.**
- «исправляют ошибки автора, а не его стиль, то есть авторскую глухоту, а не авторскую
  вольность.» (Ч.I) *(главное различение)*
- «обе эти ошибки редактор должен увидеть, но не сможет исправить. Это дело автора.»

- «автор обязан быть логичным, но он не обязан знать теорию логики.» (Ч.III) *(не грузить
  автора терминами)*
- «Критерий авторской вольности – намеренность, выделенность, которые хорошо
  ощущаются слушателем, читателем.» (Ч.IV) *(вольность vs глухота)*

**Применение.** Режим Восстановление — `references/recovery.md` (диагностика входа,

### Task 3: recovery.md — НОВЫЙ файл режима Восстановление

**Files:**
- Create: `skills/infostyle/references/recovery.md`

- [ ] **Step 1: Создать файл с полным содержимым**

```markdown
# recovery — режим Восстановление (для LLM-мусора и ИИ-переводов)

Когда на входе не «мысль, которой надо придать форму», а **малочитаемый машинный текст**
— LLM-выход или перевод, — инфостиль работает в режиме **Восстановление**. Цель та же
(читаемый текст для человека), но вход другой, поэтому другой фронт и другая сила
правки. Источник метода — Беззубов [6].

## Когда режим Восстановление

Признаки машинного мусора (достаточно нескольких):
- дефисные EN-ru гибриды и кальки-оборотчики («жизнь заказчика упрощается»);
- канцелярит россыпью («осуществляет», отглагольные, пассив);
- оценочные стоп-слова без факта («эффективный», «инновационный»);
- плоские абзацы, текст не сканируется по диагонали;
- повторы, однокорневые рядом;
- иногда — фактические/логические сбои (галлюцинации).

Вход неоднозначен — уточните у автора или по умолчанию Формирование.

## Этос режима: голос не священен

В Формировании бережём голос автора и правим минимально. В Восстановлении автора нет —
это машина, голосу некому принадлежать. Поэтому **агрессивный рерайт допустим** вплоть
до переписывания абзацев целиком. Единственная верность — читателю. (Беззубовское
«правь ошибку, не стиль» [6] здесь снимается: стиля нет, есть обломки.)

## Конвейер

```
[мусорный LLM / перевод]
  ① ДИАГНОЗ ──── что сломано и в какой мере (метод «найти→назвать→объяснить»)
  ② ЗАМЫСЕЛ ──── польза читателю, путь А→Б, структура   ← ГЕЙТ
  ③ ПЕРЕПИСЫВАНИЕ ── агрессивный рерайт к замыслу → читаемый ЧЕРНОВИК
  ④ ПРОВЕРКА ──── sanity контента + финальная гигиена
[читаемый текст]
```

### ① Диагноз

Прочитайте текст целиком. Классифицируйте поломки методом Беззубова «найти → назвать →
объяснить» [6]: кальки? канцелярит? вода? нет архитектуры? галлюцинации? Диагноз задаёт
трудоёмкость остальных стадий.

### ② Замысел — гейт

Решите, что текст должен делать для читателя: полезное действие, читатель, путь А→Б,
структура (см. `architecture.md`). Если пользы нет и не вытащить — переписывайте с нуля
из замысла, а не латайте обломки.

### ③ Переписывание

Агрессивный рерайт к замыслу. Механика — проходы из `hygiene.md`, но в этом порядке:

1. **Де-калька (обязательно, первой).** Кальки и переводизмы — в естественный русский
   (`translationese.md`, 3 класса). В этом режиме сканер обязательный, не условный.
2. **Канцелярит → глагол** (глагол-сканер).
3. **Стоп → факт** (стоп-сканер).
4. **Повторы / паронимы / амфиболия / дисфония** (именованные проходы 10-14, `hygiene.md`).

Выход — читаемый черновик, готовый к проверке.

### ④ Проверка

- **Sanity контента.** Текст стал читаемым — теперь проверьте, правда ли это. LLM
  галлюцинирует: цифры, имена, утверждения, причинно-следственные связи. Не можете
  проверить — пометьте `[непроверено]` / `[?галлюцинация]`. **Не правьте факты молча и
  не выдумывайте** — это к автору/человеку ([6], Ч.II).
- **Финальная гигиена.** Прогоните 9+ проходов из `hygiene.md` как чек-лист.

## Чек-лист режима

- [ ] Вход диагностирован как машинный мусор (а не человеческий черновик).
- [ ] Замысел назван; пользы нет — рерайт с нуля.
- [ ] Де-калька пройдена (обязательно).
- [ ] Факты, которые не проверить — помечены, не выдуманы.
- [ ] Финальная гигиена (9+ проходов) — реально прогнана.

## Связь с Формированием

Оба режима ведут к одному стилю (Ильяхов). Формирование — лёгкая правка своего /
человеческого текста по 7-уровневому позвоночнику (`SKILL.md`). Восстановление —
тяжёлый рерайт мусора по этому конвейеру. Целевой стиль тот же; `hygiene.md`,
`architecture.md`, `translationese.md` — общие.
```
