# Шаблоны слайдов (фрейм 1920×1080, локальные координаты)

Контентная зона: x=120…1800, y=100…1000. Все размеры — стартовые, варьируй по объёму текста.

## Шкала кеглей (проектор 1080p; меньше — «мелко и сиротливо»)

| Элемент | fs |
|---|---|
| Заголовок слайда | 64 (титул — 72) |
| Подзаголовок | 30 |
| Тело (строки-тезисы) | 28 |
| Текст карточек | 26 |
| Баннер-формула | 32 |
| Крупные подписи («Метрики») | 56 |
| Пилл-надзаголовок | 18–20 |
| Номер слайда | 18 |
| Q&A | 120 |

Шаг строк тела — 64–72. Контент начинать с y≈320. Слайд с содержанием меньше
половины зоны — перерастить кегли/карточки, а не оставлять пустоту.

## Титул
- пилл-рамка «ТЕЗИС · ВОПРОС» (120, 120), роль = акцент доклада
- заголовок fs72 (120, 200), до 2 строк
- подчёркивание (120, ~420, w=120)
- подзаголовок fs30 MUTED (120, 470)
- автор fs24 (120, 550); источник fs20 FAINT (120, 600)

## Обычный слайд — шапка единым блоком
- пилл «ЧАСТЬ N · КЛЮЧ» (120, 110; низ 150)
- заголовок fs64 (120, **215**; низ 295) — зазор от пилла 65
- подчёркивание (120, **320**) — 25 от низа заголовка
- номер — `slide.number()`; контент с y=**380** (60 от линии)
Не задавай эти y по одному — сдвигай блок целиком.

## Карточки в ряд (n штук)
`w = (1680 − (n−1)·60) / n`; x = 120, 120+w+60, …; y=360; текст fs26.
Для «тройка требований»: 3 × 520px. Подпись-строка под карточками y = 360 + h + 60.

## Сравнение (2 колонки)
Слева красная карточка (анти-паттерн), справа зелёная (как надо):
x=120 w=800 и x=960 w=800, y=340. Вывод-баннер amber на всю ширину ниже.

## Поток (конвейер)
Боксы h=64 fs18 серые: w = max(len·18·0.52+40, 130); стрелки между —
`arrow(x+6, y+32, 28, 0, curve=False)`. Строки-пояснения ниже с шагом 68.

## Цикл (замкнутый луп)
4 карточки 600×130 fs26 по углам прямоугольника: (360,340) → (1060,340) →
(1060,620) → (360,620). Стрелки: вправо (974, 405, 72, 0), вниз
(1360, 484, 0, 122), влево (1046, 685, −72, 0), вверх (660, 606, 0, −122).
Подпись возврата «и снова» amber у средней стрелки. Луп обязан замыкаться.

## Строки-тезисы
`row(120, y, текст)`, шаг 64–72. Больше 5 строк на слайд — плохо:
переноси на карточки или режь.

## Баннер-формула
amber-карточка fs32 на 1000–1200px, 1–2 строки. Один на слайд, максимум два.

## Плейсхолдер скриншота
gray-карточка h=180 fs24: «[ скриншот … ]» + подпись. Реальный скриншот вставляет
владелец в Excalidraw вручную.

## Q&A
пилл «ВОПРОСЫ», «Q&A» fs120, подчёркивание, 2 строки контактов/источников fs24 MUTED.
