# Локальный критик — независимый проход перед гейтом

Локальные модели (ollama) с другим происхождением, чем GLM: T-lite-8B (Qwen3-база +
русский пост-трейн Т-Банка) и Яндекс-8B (нативный русский тренинг). Видят кальки, на
которые GLM и критик-на-GLM слепы (подтверждено: все три локальные модели ловят «боль»
в смысле pain — GLM её считает нормой).

## Когда

После гигиены и ритма, **до** диспетчеризации `infostyle-critic`. Один прогон на финальную
версию текста, не на каждую итерацию.

## Вызов

```
python3 ~/.claude/skills/infostyle/scripts/local_critic.py <файл.md>
```

(канон скрипта — `agent-knowledge/skills/infostyle/scripts/local_critic.py`; деплой —
симлинк, работает из любого cwd)

- дефолт `--models t-lite,yandex` — быстрый дуэт (~3–4 мин на 30 абзацев);
- `--models qwen,yandex` — финальный прогон важных артефактов (релиз-нотс, внешние
  документы): Qwen3-14B глубже, но ~2–3× медленнее;
- ollama не запущена → скрипт напечатает предупреждение и выйдет без ошибки — шаг
  пропускается, работа не блокируется.

## Применение замен — ГЛАВНОЕ

Скрипт **не применяет ничего** — только отчёт «цитата → замена». Применяет GLM, построчно,
через Edit по точной цитате. Каждую замену фильтруй:

**Принимай:** кальки («on-demand» → «по запросу»), машинные связки («качает» →
«скачивает»), переводизмы («не доезжают» → «не доходят до»), канцелярит.

**Отвергай — замены, трогающие:**
- термины и имена продуктов: RBAC, OCI, чарт (helm chart), сид/сидер, TO-BE,
 VictoriaMetrics — модели предлагают их «расшифровать» или заменить («OCI» → «объектные
	капсулированные изображения» — выдумка Яндекса, реальный случай);
- код в обратных кавычках, пути, ссылки, числа, версии;
- прямые цитаты заказчиков (инвариант дословности);
- жирные выделения и структуру — замена не должна менять разметку.

**Не сопоставлено с текстом** (цитата не найдена дословно) — не применять вовсе; возможна
галлюцинация. Разобрать глазами только если подозрение обоснованное.

## Дуэт = два взгляда

T-lite и Яндекс дают пересекающиеся списки с разными слепыми зонами: T-lite дисциплинирован
и находит связки, Яндекс ловит живость («не доезжают» → «не доходят до»). Замена от любой
модели проходит один и тот же фильтр. Конфликты (две замены одной цитаты) — выбирай
короткую и живую.
