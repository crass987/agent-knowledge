# infostyle — проза для людей

## Управляющая мысль

Правота ничего не значит, если читатель не понял. Чистые слова без архитектуры —
натёртый пол в доме без стен. **Сначала архитектура, потом гигиена.**

## Что такое «сдано»

Текст сдан, когда он **звучит так, будто его сказал живой человек**. Всё остальное —
стоп-сканеры, счётчик длин предложений, каталоги кальк — это **подсказки, не приговор**.
Прогнать сканер и решить «чисто» — главная ошибка: формально чистый текст бывает мёртвым.

## Пять вещей, которые я по умолчанию делаю НЕ так

Ради них скилл и нужен; остальное я и так делаю.

1. **Кальки of-phrase из английского.** «Работы уровнем выше», «детализация на уровне
   хостов» ← *at the host level*. Главный брак в текстах из EN-канона (NMT, код, доки,
   LLM); стоп-сканер слеп к ним. → `references/translationese.md` (класс 1 — первым).
2. **Сжимаю документ как лендинг.** Для аналитики / стратегии / меморандума / документации
   плотность — анти-ценность: получается мёртвый конспект. Рабочий документ **организуют,
   не сжимают**: выводы в начала разделов, связки, расшифровка терминов. →
   `references/genres.md` §«Рабочие / аналитические документы».
3. **Забываю пример.** Троица: абстракция + пример + антипример. Без примера мысль не
   нужна; труд примера — 80%. «Сокращай мусор, не примеры». → `references/troitsa.md`.
4. **Пишу монотонно.** Все предложения одной длины — главный маркер машинного текста.
   Чередуй длины; у абзаца есть дуга: зачин → развитие → удар. → `references/rhythm.md`.
5. **«Информирую» вместо «помогаю».** Полезное действие — зачем читателю читать;
   «информировать» — не польза. Деятельная забота: не сообщить, а помочь решить. →
   `references/architecture.md`.

## Дисциплина (чего НЕ делать)

- **Не сдавать по сканерам.** Список в `references/hygiene.md` — каталог частых дефектов,
  не чек-лист «выполнено». Прогнал — и идёшь читать глазами.
- **Не применять лендинг-настрой к документу.** Телеграф / выжимка — только для лендинга,
  релиз-нотс, анонса. Жанр задаёт настрой плотности (Шаг 0 ниже).
- **Не вытравливать местоимения.** «Наивный инфостиль»: мёртвый текст без «мы / вы».
  Текст звучит как речь; удаляем только избыточное.
- **Не править факты молча.** Не уверен — флаг `[?]`, не выдумывай.

## Шаг 0. Жанр → настрой плотности (до применения)

| Жанр | Настрой |
|---|---|
| Лендинг, релиз-нотс, анонс | плотность = ценность: телеграф, сильная позиция, одна мысль на 3–5 предложений |
| Статья, пост | гигиена да, плотность мягче, сцены и примеры |
| **Рабочий / аналитический документ, документация** | **организовать, не сжать**: гигиена да (стоп, кальки, факт), телеграф — нет; связки, расшифровки, объяснительный слой |

Жанр или читатель неясны — спроси. Не применяй лендинг-настрой к длинному аналитическому
тексту по умолчанию: это даёт мёртвый пересушенный документ.

## Сначала диагноз: Формирование или Восстановление

| | **Формирование** | **Восстановление** |
|---|---|---|
| Вход | своя мысль / человеческий текст | LLM-мусор / ИИ-перевод |
| Сила правки | лёгкая–средняя | тяжёлый рерайт |
| Голос автора | сохраняем | не священен (автор — машина) |
| Кальки | условно | обязательно |
| Маршрут | позвоночник ниже | конвейер в `references/recovery.md` |

Признаки мусора: дефисные EN-ru гибриды, кальки-оборотчики, канцелярит россыпью,
стоп-слова без факта, плоские абзацы. Машинный вход → `references/recovery.md`.

## Порядок работы

**Новый текст:** архитектура (полезное действие → контекст → структура) → троица →
гигиена → ритм → **критик**.

**Редактура готового:** часто дешевле сначала пройти гигиену — архитектурные провалы
вскроются сами (оценка без факта обычно маскирует отсутствие полезного действия).

## Приёмка: независимый критик — ОБЯЗАТЕЛЬНО

Перед сдачей диспетчеризуй **агент-тип `infostyle-critic`** — свежий саб-агент, который
не писал этот текст и читает его холодным глазом. У него отобраны все инструменты кроме
`Read`, поэтому он **физически не может** грепать или считать паттерны — только читать
как человек. Вызов:

```
Agent(subagent_type="infostyle-critic", prompt="<текст на проверку>")
```

Он вернёт вердикт `ЖИВОЙ` / `НА ГРАНИ` / `МЁРТВЫЙ` + 3 худших предложения с
переписками. **Его вердикт — финальный гейт**, не твой самоотчёт по сканерам. Себя по
сканерам не сертифицируешь — корневая ошибка, ради устранения которой критик существует.

Подсказка: хук `Stop` в харнессе блокирует сдачу, если ты вызвал `infostyle`, но не
запустил `infostyle-critic` в этом ходу. Не обходи — просто пусти критика.

Много доков — критик на каждый док отдельным саб-агентом (см.
`superpowers:dispatching-parallel-agents`).

## Ремесло: заголовок статьи / лендинга / анонса

Заголовок продаёт чтение; жанр — **польза читателю**, не название работы (заголовок
задачи / issue / PR — в скилле `jtbd`).

- Прямо называет тему с первого взгляда; понятность важнее креатива (без антитез, рифм,
  фразеологизмов; тест «есть ли ход или приём?» → прямая номинация).
- Опора на пользу читателю, не на продукт; конкретика-цифра из контекста («дороже» → с
  ценами).
- Сужайте аудиторию («бухгалтер» → «бухгалтер для салона красоты»); сильная позиция —
  суть в первые слова.

Прогрессия: `Бухгалтер` → `Бухгалтер для салона красоты` → `… Первичка и учёт за N ₽/мес`.

## Референсы (грузить по необходимости)

`translationese` (кальки, allowlist — всегда для EN-источника) · `genres` (рабочие /
аналитические документы) · `troitsa` (пример + антипример, ментальный фильм) · `rhythm`
(правило волны, дуга абзаца) · `architecture` (полезное действие, контекст, структура,
сверхзадача) · `hygiene` (каталог дефектов: стоп, глагол, канцелярит, паронимы…) ·
`markdown-layout` (список / таблица / проза по форме данных) · `recovery` (режим
Восстановление) · `_shared/infostyle-core.md` (базис: стоп-слова, факт, мета-слой; общий
с `jtbd`).

Жанры пресс-релиз / слайды / холодное письмо / отклик и журнальная подача — в `archive/`.
